# Грузовая доставка БАС-200

Материалы проекта по сравнению стоимости доставки грузов автомобилем и БПЛА БАС-200 в удалённые населённые пункты России. Снимок файлов от 10 ноября 2026 года.

## Файлы проекта

| Файл | Содержание |
| --- | --- |
| [Карта трёх аэропортов](map.html) | Интерактивная карта Каргасока, Криволуцкой и Газимурского Завода с выбранными поселениями, связями и количеством полётов за месяц. Соответствует компактной таблице. |
| [Очищенная база аэропортов](airports_cleaned.xlsx) | Итоговый каталог 757 объектов, использованный в последней модели, с отдельными листами ручных исключений и исходных сведений. |
| [База населённых пунктов](settlements.csv.zip) | Полная исходная база: 159 486 записей с координатами и населением. В ZIP лежит файл settlements.csv без изменения содержимого. |
| [Компактная итоговая таблица](calculations_compact.xlsx) | Три выбранных аэропорта: Каргасок, Криволуцкая и Газимурский Завод; 20 направлений, 186 полётов в месяц. |
| [Общая итоговая таблица](calculations_full.xlsx) | Общая подборка семи аэропортов с положительной суммарной экономией и не менее 60 полётов в месяц до дополнительного отбора трёх аэропортов. |

В обеих расчётных книгах три листа: «Оптимум по аэропортам», «Выбранные направления» и «Все направления». Общая книга включает направления аэропортов, прошедших экономический отбор; она не является таблицей всех поселений России.

## Принятые условия расчёта

- БАС-200: до 162 км в одну сторону по прямой, скорость 100 км/ч, стоимость 12 390 ₽ за лётный час.
- Грузовик: 2 100 ₽/ч; число поездок в каждое поселение — min(9, число полётов дрона за месяц).
- Расчётный месяц — 30 дней; ограничение численности населения сверху снято.
- Загрузка — 0,25% полной загрузки на человека в день; число полётов равно целой части месячного спроса.
- Дорожный подъезд — не менее 4 часов; в модели применены скорости 90 / 60 / 40 / 15 км/ч по группам дорог.
- Для каждого аэропорта выбирается набор направлений с максимальной суммарной экономией при не менее 60 полётов за месяц. Возможен необходимый убыточный добор до порога.

## Как открыть

Таблицы скачайте кнопкой **Download raw file** на странице файла и откройте в Excel. Базу поселений сначала распакуйте; CSV использует разделитель «точка с запятой» и кодировку UTF-8 с BOM.

Карту **map.html** скачайте и откройте в браузере. Для фоновых карт нужен интернет. Просмотр HTML-кода на GitHub не запускает интерактивную карту.

## Происхождение данных

- Каталог аэропортов подготовлен на основе [airports.csv](https://davidmegginson.github.io/ourairports-data/airports.csv) и [runways.csv](https://davidmegginson.github.io/ourairports-data/runways.csv) базы OurAirports, с дополнениями и ручными исключениями проекта.
- База поселений: [NickyX3/russia_settlements](https://github.com/NickyX3/russia_settlements), основа — набор ИНИД «Населённые пункты России: численность населения и географические координаты».
- Дорожные расчёты: OSRM и данные © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), полученные через [Geofabrik](https://download.geofabrik.de/russia.html).

Каталог аэропортов отражает входные данные расчётной модели: наличие записи в нём само по себе не является подтверждением текущего эксплуатационного статуса объекта.
